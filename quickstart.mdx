title: "Quickstart"
description: "Get a quote, send the swap, check the result."
---

Four steps. You need a wallet address, two token addresses and an RPC for your chain.

The base URL is `https://api.metadexa.io`. Paths start with `/v1.0`.

## 1. Get a quote

<CodeGroup>
```bash curl
curl "https://api.metadexa.io/v1.0/10/getQuote?\
sellTokenAddress=0x1111111111111111111111111111111111111111&\
buyTokenAddress=0x2222222222222222222222222222222222222222&\
sellTokenAmount=1000000000000000000&\
slippage=0.01&\
fromAddress=0x4444444444444444444444444444444444444444"
```

```ts TypeScript
const params = new URLSearchParams({
  sellTokenAddress: "0x1111111111111111111111111111111111111111",
  buyTokenAddress: "0x2222222222222222222222222222222222222222",
  sellTokenAmount: "1000000000000000000", // 1 token, 18 decimals
  slippage: "0.01", // 1%
  fromAddress: "0x4444444444444444444444444444444444444444",
});

const response = await fetch(`https://api.metadexa.io/v1.0/10/getQuote?${params}`);
if (!response.ok) throw new Error(await response.text());
const quote = await response.json();
```
</CodeGroup>

`10` is the chain ID (Optimism here). Amounts are integers in the token's smallest unit, sent as strings.

The response:

```json
{
  "estimatedGas": 150000,
  "buyTokenAddress": "0x2222222222222222222222222222222222222222",
  "buyAmount": "1000000",
  "sellTokenAddress": "0x1111111111111111111111111111111111111111",
  "sellAmount": "1000000000000000000",
  "allowanceTarget": "0x3333333333333333333333333333333333333333",
  "tx": {
    "from": "0x4444444444444444444444444444444444444444",
    "to": "0x3333333333333333333333333333333333333333",
    "data": "0x",
    "gas": 200000,
    "value": "0",
    "gasPrice": "100000000"
  }
}
```

(Values are fake.)

## 2. Approve the token

Skip this for the native token. Otherwise let `allowanceTarget` spend your sell token. See the [swap guide](/swap-guide#token-approvals).

## 3. Send the transaction

`tx` is ready to sign. Send it as is.

```ts
import { createWalletClient, custom } from "viem";

const wallet = createWalletClient({ transport: custom(window.ethereum) });

const hash = await wallet.sendTransaction({
  account: quote.tx.from,
  to: quote.tx.to,
  data: quote.tx.data,
  value: BigInt(quote.tx.value),
  gas: BigInt(quote.tx.gas),
});
```

## 4. Check the result

Wait for the receipt and check its status.

```ts
import { createPublicClient, http } from "viem";

const client = createPublicClient({ transport: http("YOUR_RPC_URL") });
const receipt = await client.waitForTransactionReceipt({ hash });

if (receipt.status !== "success") throw new Error("Swap reverted");
```

<Tip>
Quotes go stale fast. Fetch a fresh one right before the user signs.
</Tip>
