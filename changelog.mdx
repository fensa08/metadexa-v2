## Versioning

The version is in the path: `/v1.0/...`. Breaking changes will go in a new version, and we'll note them here.

## 1.0

Current version.

- Quotes: `getQuote` and `getGaslessQuote`
- Referrals: `registerReferrer`, `checkReferrer`, `addTransaction`, `verifyTransaction` and `referrer`
- Chains: Ethereum, Optimism, Polygon, Arbitrum One and Base
