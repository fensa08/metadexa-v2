<Warning>
Check these addresses against the contract deployments before you hardcode them. Prefer reading `allowanceTarget` from each quote.
</Warning>

## Native token

Use `0xeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee` for the chain's native token. It needs no approval, and `allowanceTarget` comes back as the zero address.

## Chain quirks

- **Optimism (`10`):** send `sellTokenAmount`. A `buyTokenAmount`-only request fails.
- **Referrals:** Optimism only.
